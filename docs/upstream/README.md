# 上游归档（dsh-vscode-mode）

本目录保存 CursorLike 的 fork 来源：**[Lenonss/DSH_VsCodeMode](https://github.com/Lenonss/DSH_VsCodeMode)** `0.20.2`（MIT）的发行说明与部分架构文档。

| 文件 | 说明 |
|---|---|
| `release-*.md` | 上游各版本（0.13 – 0.20）发布说明，保留用于追溯历史决策 |
| `commands.md` | 上游指令系统（Command Palette / 命令目录 / 键位桥）架构说明 |
| `sidebar-extension-contract.md` | 上游 DSH 官方侧栏 API 对接说明 |
| `version-adaptation.md` | 上游 DSH 版本适配记录 |

注意：

- 这些文档描述的是 **fork 之前的上游实现**，其中的包名、设置项（SVN/MCP/Unity/系统集成等）与部分命令可能已在 CursorLike 中删除或改造；
- 当前功能、安装与开发说明以仓库根 [README.md](../../README.md) 和 [../CursorLike-plan.md](../CursorLike-plan.md) 为准；
- 许可证与版权声明见仓库根 [LICENSE](../../LICENSE)，上游署名同时保留在 README「与上游的关系」一节。
